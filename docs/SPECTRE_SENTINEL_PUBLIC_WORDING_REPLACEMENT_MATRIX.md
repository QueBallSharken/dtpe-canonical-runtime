# SPECTRE-SENTINEL PUBLIC WORDING REPLACEMENT MATRIX

## Status

This artifact defines safe replacement wording for public Sentinel language.

It exists to replace unsafe wording patterns with bounded collaboration-safe repo wording.

---

## 1. Purpose

This artifact provides a replacement matrix for Sentinel wording so that collaboration surfaces stay consistent with the bounded future-integration package.

---

## 2. Replacement Matrix

| Unsafe wording | Safe replacement |
|---|---|
| Sentinel is a runtime layer | Sentinel is a future integration profile |
| Sentinel evaluates at the boundary | Sentinel feeds canonical semantic artifacts for later boundary evaluation |
| Sentinel replaces SPECTRE | Sentinel remains subordinate to SPECTRE |
| Sentinel solves BBIS | Sentinel may support a future BBIS-constrained architecture but does not complete BBIS |
| Sentinel is already integrated | Sentinel is positioned for future integration |
| Sentinel is a completed architecture layer | Sentinel is a bounded future direction |
| Sentinel provides end-to-end continuity | Sentinel may improve ingress posture without implying full-path continuity |
| Sentinel is verifier-complete | later verifier compatibility would require explicit receipt / ledger / replay extensions |
| Sentinel authorizes runtime work through IAL | IAL ownership does not imply runtime authorization |
| Sentinel governs all mutation paths | any claims remain path-bounded and mutation-bounded |

---

## 3. Usage Rule

Use the safe replacement wording whenever:
- public repo language is updated
- collaboration notes are prepared
- handoff material is written
- future integration is discussed in repo docs

---

## 4. Completion Rule

This matrix is being used correctly only when unsafe wording is actively replaced rather than merely flagged.

---

## 5. Direct Rule

The direct rule is:

If Sentinel wording sounds broader than future integration through IAL and SPECTRE, replace it with the bounded form in this matrix.
