# SPECTRE-SENTINEL NON-GOALS

## Status

This artifact defines the explicit non-goals for future Sentinel integration.

It is intentionally strict.

It exists to prevent scope drift and implied runtime expansion.

---

## 1. Purpose

This artifact records what future Sentinel integration is not trying to accomplish in the current bounded repo posture.

---

## 2. Non-Goals

The following are non-goals for the current future-integration package:

- normalizing Sentinel as a current public runtime layer
- replacing SPECTRE
- replacing DTPE
- replacing IAL
- claiming BBIS completion
- claiming full mutation-bound continuity
- claiming end-to-end workflow governance
- claiming universal downstream path governance
- claiming verifier completeness without explicit receipt / ledger / replay extension
- claiming full PQC migration
- claiming full crypto-agility completion
- claiming runtime authorization by implication from IAL positioning

---

## 3. Why These Non-Goals Matter

Without explicit non-goals, future integration language can drift into:
- implied runtime authorization
- implied architectural replacement
- implied continuity completion
- implied verifier completion

This artifact exists to block that drift.

---

## 4. Direct Rule

If a proposed Sentinel statement sounds like current runtime normalization, architectural replacement, BBIS completion, or verifier completion, it is outside the non-goal boundary and must be rejected or rewritten.
