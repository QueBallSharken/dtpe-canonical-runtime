# SPECTRE-SENTINEL COLLABORATION SOURCE OF TRUTH RULE

## Status

This artifact defines the source-of-truth rule for Sentinel future-integration collaboration.

It is repo-facing only.

It exists to keep future collaboration anchored in repo artifacts rather than off-repo context.

---

## 1. Purpose

This artifact defines how Sentinel future-integration work should be carried forward in later collaboration.

---

## 2. Source-of-Truth Rule

For Sentinel future-integration work, authority order is:

1. repo docs
2. repo acceptance / planning artifacts
3. repo implementation artifacts
4. off-repo discussion only as temporary drafting context

The repo must remain the source of information for later collaboration.

---

## 3. Collaboration Rule

Future collaboration should:
- use repo artifacts as the primary reference
- avoid relying on hidden background context
- avoid relying on thread memory for architecture meaning
- update repo artifacts when meaning changes
- keep public wording bounded and consistent

---

## 4. Handoff Rule

If work is handed off to another collaborator or another thread, the handoff should point to:
- repo artifacts first
- repo index artifacts second
- specific bounded package docs third

It should not depend on reconstructing meaning from chat history.

---

## 5. Direct Rule

The direct rule is:

For Sentinel future-integration work, the repo is the source of truth for collaboration, interpretation, and follow-on work.
