# SPECTRE-FST FIRST TARGET EXPECTED OUTPUTS

## STATUS

This document defines the expected bounded outputs for the first SPECTRE-FST target.

It is architecture-facing only.

---

## 1. PURPOSE

The first target should not leave output expectations implicit.

This document defines the expected output shape and bounded interpretation.

---

## 2. REQUIRED OUTPUTS

A conformant first target should emit:

- one explicit primary result
- one bounded receipt shape
- bounded findings
- bounded gaps
- bounded contradictions
- bounded interpretation of the result
- explicit non-claim boundary

---

## 3. SAFE EXPECTED PRIMARY RESULTS

For the current first-target scenario, safe expected primary outputs include:

- PARTIAL
- UNVERIFIABLE
- CONTRADICTION_EXPOSED

A STRONG result should not be expected from the currently bounded scenario without stronger supporting evidence.

---

## 4. SAFE EXPECTED FINDINGS

Safe first-target findings may include:

- local refusal boundary remained live
- one claimed boundary remained supportable
- bounded receipt interpretation remained possible

---

## 5. SAFE EXPECTED GAPS

Safe first-target gaps may include:

- system-wide refusal continuity not strongly evidenced
- later boundary continuity not proven strongly enough
- trace or proof surface insufficient for stronger claim

---

## 6. SAFE EXPECTED CONTRADICTIONS

Safe first-target contradictions may include:

- stronger continuity claim exceeded evidenced scope
- claimed system-wide continuity not supported by the bounded scenario
- stronger claim was not downgraded when required

---

## 7. FINAL RULE

The first target output must remain narrow, deterministic, and bounded by the explicit scenario and rule profile.
