# SPECTRE-SENTINEL PUBLIC WORDING GUARDRAILS

## Status

This artifact defines public-wording guardrails for future Sentinel integration.

It is intended to prevent public contradiction and implied authorization drift.

---

## 1. Purpose

This artifact defines safe and unsafe wording patterns for Sentinel future-integration language.

---

## 2. Safe Wording Patterns

Safe wording includes:
- Sentinel is a future integration profile
- Sentinel is a future semantic / interception ingress layer
- Sentinel feeds IAL-native canonical semantic artifacts
- SPECTRE remains the execution / mutation-bound evaluator
- DTPE remains the evidence path
- BBIS remains the continuity requirement
- docs alignment and README alignment are required before normative publication

---

## 3. Unsafe Wording Patterns

Unsafe wording includes:
- Sentinel is now a public runtime layer
- Sentinel replaces SPECTRE
- Sentinel closes BBIS
- Sentinel provides full mutation-bound continuity
- IAL positioning authorizes Sentinel runtime work
- verifier integration is complete
- end-to-end continuity is solved
- universal live refusal is now provided

---

## 4. Direct Rule

If a public sentence makes Sentinel sound present-tense normalized, boundary-replacing, BBIS-closing, or verifier-complete, the sentence must be rejected or rewritten.
