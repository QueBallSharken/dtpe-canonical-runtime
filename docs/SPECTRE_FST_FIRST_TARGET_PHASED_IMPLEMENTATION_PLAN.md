# SPECTRE-FST FIRST TARGET PHASED IMPLEMENTATION PLAN

## STATUS

This document defines the phased implementation plan for the first bounded SPECTRE-FST target.

It is architecture-facing only.

---

## 1. PURPOSE

The first target should be built in narrow bounded phases.

This plan defines that order.

---

## 2. PHASED PLAN

### Phase 1 — Bounded Architecture Lock
Required:
- minimal architecture profile
- result vocabulary
- receipt schema
- first target acceptance rules

### Phase 2 — First Scenario Lock
Required:
- one explicit scenario
- one selected stress category
- one selected rule profile
- one bounded expected result discipline

### Phase 3 — Receipt-Bearing Evaluation
Required:
- deterministic evaluation shape
- one receipt-bearing result
- findings, gaps, contradictions
- bounded interpretation

### Phase 4 — Proof and Review
Required:
- proof harness run against first scenario
- result reviewed against acceptance rules
- stronger non-claims preserved

---

## 3. FINAL RULE

The first target should not expand breadth before proving bounded evaluator reality.

Depth before breadth.
